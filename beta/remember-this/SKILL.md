name: remember-this
description: Save a durable finding or decision to the shared Obsidian vault when asked to remember something; not a session transcript or task log.
model: sonnet
---
Use the vault and placement rules in the user's or repository instructions; read its memory guide and the relevant existing note before writing. If unavailable, report the blocker without creating another memory store.
Extract only reusable knowledge, its scope and why it matters; verify technical claims against current evidence and distinguish a user decision or uncommitted idea from an established fact.
Search for the same knowledge first; amend the existing note or create one in the appropriate location, keeping one canonical account and preserving unrelated content.
Record the source and verification date for facts that can change; exclude credentials, transcripts and temporary session state. Return the note link and a sentence describing what was saved. Follow [language.md](../../references/language.md).
